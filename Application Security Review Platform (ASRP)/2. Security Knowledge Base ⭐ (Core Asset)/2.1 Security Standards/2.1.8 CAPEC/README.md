# 2.1.8 CAPEC Attack Pattern Module

## 📌 Overview
Common Attack Pattern Enumeration and Classification (CAPEC) dictionary specifying adversary attack tactics for threat modeling and Red Teaming.

## 📄 Specification Files
- `index.yaml`: Module metadata catalog.
- `capec-top-attack-patterns.yaml`: Top CAPEC attack patterns mapped to CWE IDs (SQLi, Cmd Injection, BOLA, Path Traversal, XSS, SSRF, Deserialization).
