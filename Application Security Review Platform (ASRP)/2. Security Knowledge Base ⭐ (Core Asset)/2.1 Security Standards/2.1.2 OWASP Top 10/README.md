# 2.1.2 OWASP Top 10 Security Risks Module

## 📌 Overview
Contains the top 10 security vulnerability risks for Web Applications (2021) and Web APIs (2023).

## 📄 Specification Files
- `index.yaml`: Module metadata catalog.
- `owasp-top10-2021.yaml`: OWASP Top 10 Web Application Security Risks 2021 (A01 - A10).
- `owasp-api-top10-2023.yaml`: OWASP API Security Top 10 2023 (API1 - API10).
