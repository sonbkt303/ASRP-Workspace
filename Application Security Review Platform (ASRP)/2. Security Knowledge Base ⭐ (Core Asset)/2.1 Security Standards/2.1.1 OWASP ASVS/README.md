# 2.1.1 OWASP ASVS Standard Module

## 📌 Overview
The **Application Security Verification Standard (ASVS)** v4.0.3 defines detailed security requirements for web applications, APIs, and microservices across 14 chapters (V1 to V14).

## 📄 Specification Files
- `index.yaml`: Module metadata catalog.
- `owasp-asvs-v4.0.3.yaml`: Full specification containing requirements for Chapters V1 through V14.
