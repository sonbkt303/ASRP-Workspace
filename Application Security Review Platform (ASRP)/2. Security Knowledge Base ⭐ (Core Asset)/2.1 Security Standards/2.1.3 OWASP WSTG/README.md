# 2.1.3 OWASP Web Security Testing Guide (WSTG) Module

## 📌 Overview
Provides penetration testing procedures and test case specifications for Web Applications and APIs.

## 📄 Specification Files
- `index.yaml`: Module metadata catalog.
- `owasp-wstg-v4.2.yaml`: Full WSTG v4.2 test cases categorized by testing domains (INFO, CONF, IDNT, ATHN, ATHZ, SESS, INPV, ERRH, CRYP, BUSL, CLNT).
