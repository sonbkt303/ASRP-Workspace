# 2.1.10 Internal Standards & Industry Compliance Module

## 📌 Overview
Legal and industry compliance standards including PCI-DSS v4.0 (Payment Security), ISO/IEC 27001:2022 (Information Security), HIPAA (Healthcare), GDPR, and Vietnam Decree 13/2023/NĐ-CP (Personal Data Protection).

## 📄 Specification Files
- `index.yaml`: Module metadata catalog.
- `hipaa-gdpr-pci-compliance.yaml`: Baseline compliance specifications.
- `pci-dss-v4.0.yaml`: PCI-DSS v4.0 detailed requirements.
- `iso-27001-annex-a.yaml`: ISO 27001 Annex A controls.
- `nd-13-2023-bhtdcn.yaml`: Vietnam Decree 13/2023/NĐ-CP personal data protection controls.
