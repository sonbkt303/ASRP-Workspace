# Foundations Core

`core/` chứa những nền tảng cốt lõi để sau này bạn ghép thành năng lực security thực hành.

Quy ước phạm vi:
- `core/` tập trung kiến thức nền tảng, hạn chế rẽ sang domain ứng dụng cụ thể quá sớm.
- Mỗi mục con có `README.md` riêng để ghi roadmap học (chưa tạo bài chi tiết).

Các nhánh hiện có:
- `computer-science/`
- `programming/`
- `cryptography/`
- `linux/` (tạm để trống theo roadmap hiện tại)
